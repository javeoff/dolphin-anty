# FAQ

Frequently asked questions about Dolphin {anty}.

## General

**What is Dolphin {anty}?**

Dolphin {anty} is an antidetect browser for managing multiple accounts simultaneously. Each browser profile has its own isolated fingerprint, cookies, and storage, making each one appear as a completely separate device to websites.

**What can I use it for?**

Affiliate marketing, media buying, e-commerce multi-accounting, web scraping, social media management, bonus hunting, and any task requiring multiple separate browser identities.

**Is it free?**

Yes, there is a **Free plan** with 5 browser profiles and no time limit. Paid plans start at $10/month for more profiles and features.

## Accounts & Profiles

**How many profiles can I create?**

Depends on your plan: Free (5), Starter (60), Base (100), Team (300), Enterprise (Unlimited). Custom plans are also available.

**Can I use the same Dolphin {anty} account on multiple devices?**

Yes. You can log into the same account from multiple devices simultaneously without being blocked.

**What are the optimal fingerprint settings for a new profile?**

Use the **default settings**. They are set by the development team and represent the most authentic configuration. Only change them if you have a specific technical reason.

**Can I transfer profiles from another antidetect browser?**

There is no direct integration with other antidetect browsers. You can manually copy cookies and user-agent strings into Dolphin {anty} profiles.

## Team & Collaboration

**Is Dolphin {anty} good for team work?**

Yes. It was built with team collaboration in mind. You can add team members, assign roles, share specific folders and profiles, and set granular permissions.

**How many users are included in each plan?**

By default, each plan includes 1 user (the admin). Additional users can be purchased. Custom plan includes unlimited users.

**Can I control what each team member sees?**

Yes. Share specific folders with specific users and set their permission level (view, edit, full access).

---

## Extensions

**How do I add browser extensions to profiles?**

Go to **Main Menu → Extensions** and install extensions there. Do **not** install extensions from inside individual profiles — this is a common mistake for new users.

---

## Proxies

**What proxy types are supported?**

HTTP, HTTPS, SOCKS4, and SOCKS5.

**Do I need a proxy for every profile?**

You don't have to use proxies, but for multi-accounting purposes (especially on platforms like Facebook), assigning a unique proxy to each profile is strongly recommended to prevent account linking.

**Should I use residential or datacenter proxies?**

Residential or mobile proxies for high-risk platforms (Facebook, Google, Amazon). Datacenter proxies are acceptable for web scraping and low-sensitivity tasks.

---

## Subscription & Billing

**What is the minimum subscription period?**

1 month. There are no annual-only plans.

**Can I get a plan between the standard options?**

No custom tier between preset plans. If preset plans don't fit, use the **Custom** plan for a personalized quote.

**What happens to my profiles if I downgrade?**

Profiles exceeding the new plan's limit become inactive but are not deleted. They can be reactivated by upgrading again.

## Technical

**Does Dolphin {anty} support automation?**

Yes. It supports Selenium, Puppeteer, Playwright, and has both a Local API and Remote API for programmatic control. There is also a no-code Scenario Builder.

**What operating systems are supported?**

Windows, macOS, and Linux.

**Is cloud sync mandatory?**

No. You can disable cloud sync in settings and keep all profiles stored locally on your device.
