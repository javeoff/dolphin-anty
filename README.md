# Dolphin {anty} Documentation

**Dolphin {anty}** is an antidetect browser for multi-accounting that helps you manage any number of accounts for advertising platforms, social networks, web scraping, marketing, affiliate marketing, and more.

## What is Dolphin {anty}?

Dolphin {anty} lets you create and manage multiple isolated browser profiles, each with its own unique fingerprint. Each profile appears as a separate device to websites, preventing account bans and enabling safe multi-account operations.

**Key value proposition:** Run hundreds of accounts simultaneously with minimal resource consumption, full team collaboration, and powerful automation tools.

## Who is it for?

- **Affiliate marketers & media buyers** — manage multiple ad accounts on Facebook, Google, TikTok
- **E-commerce sellers** — operate multiple storefronts on Amazon, eBay, Shopify
- **Digital agencies** — manage client accounts without cross-contamination
- **Web scrapers** — collect data without detection
- **Bonus hunters** — run multiple accounts on betting and gaming platforms
- **Social media managers** — handle multiple brand profiles
