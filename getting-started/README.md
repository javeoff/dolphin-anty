# Quick Start

Get up and running with Dolphin {anty} in under 10 minutes.

## Step 1: Create an Account

1. Go to [dolphin-anty.com](https://dolphin-anty.com/)
2. Click **Create account** in the top right
3. Complete registration — the **Free plan** gives you 5 browser profiles at no cost

## Step 2: Download and Install

Download the desktop application for your operating system:

- **Windows** — download the `.exe` installer
- **macOS** — download the `.dmg` file
- **Linux** — download the `.AppImage` or `.deb` package

See [Installation](installation.md) for detailed instructions.

## Step 3: Log In

Open Dolphin {anty} and log in with the credentials you created in Step 1. The same account can be used across multiple devices simultaneously.

## Step 4: Create Your First Profile

1. Click **Create Profile** in the main interface
2. Give the profile a name (e.g., "FB Account 1")
3. Leave fingerprint settings at their defaults — these are optimized by the development team
4. (Optional) Add a proxy — see [Proxy Management](../features/proxies.md)
5. Click **Save**

## Step 5: Launch the Profile

Click the **Start** button next to your profile. A new browser window opens — this is your isolated profile with its own fingerprint, cookies, and storage.

## Tips for New Users

- **Use default fingerprint settings** when creating profiles — they represent the most optimal configuration
- **Add extensions from the main menu**, not from inside individual profiles
- **Enable cloud sync** to access profiles from any device
