# Features Overview

Dolphin {anty} provides a comprehensive set of tools for multi-account management, fingerprint spoofing, team collaboration, and automation.

## Core Features

| Feature | Description |
|---------|-------------|
| [Browser Profiles](profiles.md) | Create and manage isolated browser profiles with unique identities |
| [Fingerprint Management](fingerprints.md) | Customize 20+ browser fingerprint parameters |
| [Proxy Management](proxies.md) | Assign and manage proxies per profile |
| [Team Collaboration](teamwork.md) | Share profiles, assign roles, manage permissions |
| [Automation & API](automation.md) | Automate with Selenium, Puppeteer, Playwright, or REST API |
| [Synchronizer Tool](synchronizer.md) | Mirror actions across multiple profiles simultaneously |

## Highlights

### One-Click Profile Creation
Create fully configured browser profiles in seconds. Dolphin {anty} pulls real-world fingerprints so each profile looks like a genuine device.

### Mass Actions
Select multiple profiles and apply bulk operations: run scripts, export cookies, assign tags, change statuses, transfer to team members, or move to folders.

### Scenario Builder
Build automated workflows for account farming and data collection without writing code. Available on Windows, Linux, and macOS.

### Cloud Sync
All profiles and cookies sync automatically across your devices. You can also switch to local-only mode to keep data on your machine.

### Minimal Resource Consumption
Dolphin {anty} is optimized to run many profiles simultaneously without heavy CPU or RAM usage compared to running separate browser instances.
