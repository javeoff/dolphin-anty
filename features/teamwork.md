# Team Collaboration

Dolphin {anty} is designed for both solo users and teams. Plans from Base and above support multiple users with granular permission management.

## Team Structure

Every Dolphin {anty} account has one **Team Admin** (the account owner). Additional users are added as team members and can be given different levels of access.

## Adding Team Members

1. Go to **Personal Cabinet → Team**
2. Click **Add User**
3. Enter the team member's email address
4. Assign a role or set custom permissions
5. The user receives an invitation email

**Pricing for additional users:**
- Base plan: $10–25 per additional user/month
- Enterprise: Included users vary by plan
- Custom: Unlimited users

## User Roles and Permissions

You can control what each team member can do:

| Permission | Description |
|------------|-------------|
| View profiles | See profile list and details |
| Start/stop profiles | Launch and close browser profiles |
| Edit profiles | Modify profile settings |
| Create profiles | Add new profiles |
| Delete profiles | Remove profiles |
| Manage proxies | Add, edit, and delete proxies |
| Manage team | Add/remove users, change permissions |

## Sharing Profiles and Folders

Instead of giving full access, share specific folders with specific users:

1. Right-click a folder in the sidebar
2. Select **Share permissions**
3. Choose team members and their access level for this folder
4. Save

Team members only see what they have been given access to.

## Profile Transfer

To permanently transfer a profile to another team member:

1. Select the profile(s) with the checkbox
2. Click **Transfer** from the mass actions menu
3. Select the destination team member
4. Confirm

## Multi-Device Access

All users on the same account can log in from different devices simultaneously. Profiles sync via cloud, so team members always have the latest state.

## Account Switching

On Base plan and above, you can configure profile switching between team accounts:

| Plan | Simultaneous Accounts |
|------|-----------------------|
| Base | 2 |
| Team | 3 |
| Enterprise / Custom | 10+ |

This allows users to switch between accounts without logging out.

## Best Practices

- Create separate folders per client or campaign and share only the relevant folder
- Use **Notes** and **Tags** to communicate profile status to teammates
- Assign **statuses** (e.g., "Farming", "Ready to Run") so the team knows what each profile is doing
